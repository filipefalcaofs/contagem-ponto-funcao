# Matriz de Cobertura das HUs Oficiais — SIGVISA

Este documento registra a rastreabilidade das Histórias de Usuário oficiais do SIGVISA. As HUs descrevem cenários e regras de negócio percebidos por atores do domínio; decisões técnicas internas devem permanecer fora das HUs.

## Fonte de Verdade

- As HUs oficiais em `docs/requisitos/hus` são a fonte de verdade funcional.
- Os arquivos `.docx` oficiais são artefatos derivados dos `.md` oficiais.
- Documentos técnicos, scripts, migrations, pipeline e decisões de infraestrutura não são HUs.

## Observações da Auditoria

- `HU.36` foi criada porque a notificação de vencimento de alvará é uma história de usuário independente: o cidadão recebe aviso e age para renovar o alvará.
- Regras técnicas de migração, deduplicação, Docker, pipeline e proteção de comandos destrutivos não foram transformadas em HUs.
- Quando uma regra técnica sustenta uma experiência de usuário, a HU descreve apenas o comportamento percebido pelo ator de negócio.
